# Divide et Impera Последний рассвет — карта выживших

Публичный сайт: https://hikikamoris.github.io/last-light-map/

## Вход и заявки

- Вход выполняется через Google и Firebase Authentication.
- Новый аккаунт получает роль `player` и статус `visitor`.
- До одобрения заявки можно просматривать карту, стену и правила; игровые действия закрыты.
- Заявка на отряд хранится в Cloud Firestore. Мастер может одобрить её или отказать.
- Приказы игроков хранятся отдельно от открытых публикаций; их видят автор и мастер.
- Первый владелец проекта назначается вручную в Firebase Console после первого входа.

## Ограничения текущего этапа

- Профили, заявки и записи стены подключены к Firestore. Состояние карты, редактора и игровых показателей отрядов всё ещё хранится отдельно в браузере каждого игрока; такие изменения пока не синхронизируются между игроками.
- Раздел «Журнал» подготовлен, но автоматическая запись событий требует публикации Cloud Functions. Для этого Firebase требует тариф Blaze с привязанным платёжным аккаунтом; он пока не подключён.

## Настройка Firebase

- Google-провайдер включён; домен `hikikamoris.github.io` разрешён.
- Cloud Firestore создан в `europe-west3` в режиме production.
- Защитные правила находятся в `firestore.rules`.
- Публичные настройки веб-приложения находятся в `firebase-config.js`. Это клиентская конфигурация, а не секретный ключ. Не добавляйте в репозиторий закрытые ключи сервисных аккаунтов.
